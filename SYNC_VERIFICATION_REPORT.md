## Root Cause Analysis

### Why Most Articles Weren't Archived (94 missing archives)

Possible causes:
1. **Task Manager Not Running**: The archival task manager may not have been running when these articles were saved
2. **Task Queue Failed**: Tasks were queued but never processed
3. **Endpoint Issue**: The `/firebase/archive` endpoint may not have properly triggered archival
4. **Silent Failures**: Errors during archival weren't logged or reported

### Why GCS Uploads Failed (0/67 uploaded)

Possible causes:
1. **Storage Integration Disabled**: `ENABLE_STORAGE_INTEGRATION` setting may be `false`
2. **GCS Credentials Missing**: Google Cloud Storage credentials not configured
3. **Upload Task Not Running**: The cleanup/upload background task isn't processing uploads
4. **Storage Providers Not Initialized**: GCS storage provider wasn't available during archival

### Item ID Changes (2 articles)

The 2 articles with changed IDs suggest:
- **Duplicate Detection**: The system may have detected these URLs already existed
- **URL Matching Logic**: Matched by URL and returned existing entry's item_id
- **Not Pocket_* Format**: These aren't the problematic `pocket_*` IDs we investigated earlier
